# Support

For usage questions, [open an issue](https://github.com/aakash-kharb/AtlasWeave/issues) with the command, version, and expected behavior. For bugs, provide a small synthetic CSV/XLSX reproduction and the actual result. Never upload confidential source data, credentials, or unreviewed project exports.

Use the feature, connector, or strategy templates for proposals. Security issues belong in the private process described in [SECURITY.md](SECURITY.md). Support is community-based with no response-time guarantee.
