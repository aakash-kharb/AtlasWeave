# Community conduct

Be respectful, specific, and constructive. Welcome contributors with different backgrounds and levels of experience. Critique work without personal attacks. Harassment, discrimination, threats, publishing private information, and repeated disruptive conduct are not acceptable.

Maintainer Aakash Kharb is responsible for moderation. Responses can include a request to change behavior, removal of content, temporary participation restrictions, or a ban, depending on severity and repetition. Decisions should be explained privately where possible; reports should be handled with discretion.

For reporting, use a private contact channel listed on [the maintainer's GitHub profile](https://github.com/aakash-kharb). If none is available, open a minimal issue asking for a private reporting channel, without names, evidence, or sensitive details. A dedicated private conduct-reporting contact still needs to be configured before a broader community launch.
