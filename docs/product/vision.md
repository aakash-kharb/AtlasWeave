# Vision and scope

Discover how your data connects. Review the mappings. Give your AI agent a precise implementation plan.

The first user is someone combining spreadsheets or system exports who needs to understand whether two fields can safely join. AtlasWeave exposes the evidence and records their decision before producing an agent handoff.

The core artifact is a versioned mapping document. UI layout and generated prose are views of that document, not the source of truth.

## First milestone

Two local CSV/XLSX inputs → deterministic candidate ranking → evidence inspection → explicit review → JSON and Markdown export. Import configuration, normalization, and join requirements are recorded. No AI provider account is required.

A field mapping links columns conceptually. A join combines rows under specific rules. Record/entity matching identifies equivalent entities and is not implemented. A matching score does not prove any of these claims.

## Deferred

Final logo refinement, arbitrary transformations, composite keys, fuzzy entity resolution, multi-table planning, SQL/NoSQL/cloud/service connectors, credentials, scheduling, production execution, AI model calls, and collaborative editing. A local browser workspace is now implemented alongside the CLI.
